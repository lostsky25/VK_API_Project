# Отчёт по проекту анализа данных VK

### 1. Постановка задачи
Цель работы — изучить структуру социальной сети вокруг одного пользователя ВКонтакте и выполнить анализ данных, собранных через API VK.

Необходимо:
Получить друзей пользователя и построить граф связей.
Построить карту распределения друзей по городам.
С помощью users.search собрать набор из 1000 пользователей выбранного города.
Выделить наиболее популярные мужские и женские имена.
Построить половозрастную структуру (демографическую пирамиду).
Подготовить отчёт по работе.

### 2. Что сделано
Реализован сбор друзей пользователя через friends.get с рекурсией (граф друзей).
Построен граф связей, цветами выделены кластеры по полу.
Реализован сбор списка друзей с городами и последующая геокодировка названий городов → координаты.
Построена интерактивная карта распределения друзей по городам (Plotly Mapbox).
С помощью users.search загружено до 1000 пользователей города.
Проведён анализ имён: выделены топ-10 мужских и женских.
Построен график «половозрастной пирамиды» (population pyramid).
Все данные сохранены в CSV.
Добавлены поля широты и долготы в общий датасет.

### 3. Используемые технологии
Языки и библиотеки:
Python 3.10+
requests — HTTP-запросы к API VK и Яндекс Геокодеру
pandas — обработка и агрегация данных
networkx — построение графа друзей
matplotlib / plotly — визуализация данных
geopy или Yandex Geocoder API — координаты городов
tqdm — отображение прогресса (опционально)

Внешние сервисы:
VK API (friends.get, users.search)
Яндекс HTTP Геокодер — получение координат городов
Pandas + Plotly для визуальной аналитики
DataLens (альтернативный вариант отображения карты)

### 4. Схема работы приложения

1) Сбор данных о друзьях из VK
Используется метод friends.get
Загружается социальный граф друзей
Сохраняются: ID, пол, имя, город и т. д.

2) Построение графа связей друзей
На основе данных создаётся граф в NetworkX
Анализируются связи и выделяются компоненты
Строятся промежуточные визуализации

3) Выделение городов друзей
Из CSV извлекаются все города
Считается число друзей в каждом городе
Формируется таблица вида:
  город → количество друзей

4) Геокодирование городов (API Яндекс Геокодера)
Для каждого уникального города отправляется HTTP-запрос
Получается широта (lat) и долгота (lon)
Координаты добавляются обратно в CSV

5) Построение интерактивной карты (Plotly Mapbox)
На карту ставятся точки для всех городов
Размер точки = количество друзей
Цветовая заливка = интенсивность значений
Наведение показывает название города и число друзей

6) Сбор 1000 пользователей города (users.search)
Используется метод users.search
Выкачиваются случайные 1000 пользователей указанного города
Сохраняются поля: имя, пол, дата рождения и др.

7) Аналитика имён, пола и возраста
Находятся самые частые женские и мужские имена
Строится график популярности имён (matplotlib или Plotly)
По дате рождения строится возрастно-половая пирамида
Выявляются тенденции по возрасту и полу

8) Формирование итоговых графиков и таблиц
Графы, карты, распределения
Все результаты визуализируются в Jupyter Notebook

### 5. Выводы по результатам

Большая часть друзей сосредоточена в нескольких крупных городах — анализ CSV показывает сильную концентрацию (например, Пенза ≈ 600 человек, Москва ≈ 450).
Географическое распределение легко читать по карте, и оно хорошо подтверждает предположения о перемещениях самого пользователя.
Популярные имена в городе логично распределены, женские имена показывают меньшее разнообразие, чем мужские.
Половозрастная структура демонстрирует "провалы" определённых возрастных групп, что может быть связано с особенностями аудитории VK.
Использование Python позволяет полностью автоматизировать процесс сбора и визуализации данных.
